# Architecture Notes

## Teknologi yang disarankan
- Frontend: HTML/CSS/JavaScript atau framework web.
- Backend: Python dengan FastAPI/Flask.
- Machine Learning: implementasi Decision Tree C4.5 dan Random Forest melalui library yang sesuai.
- Database: MySQL atau PostgreSQL.
- Format pertukaran data: JSON.
- Input pengujian multi-record: CSV.

## Prinsip
CRISP-DM menjadi kerangka proses. C4.5 dan Random Forest digunakan pada modelling/evaluation, sedangkan rule C4.5 menjadi dasar deployment aplikasi sebagaimana dijelaskan penelitian.

## Catatan implementasi
Jurnal menggunakan RapidMiner untuk pembentukan model. Aplikasi web pada proyek ini merupakan adaptasi rekayasa perangkat lunak; pilihan framework backend/frontend di atas adalah rekomendasi implementasi, bukan teknologi yang diklaim digunakan penulis jurnal.
