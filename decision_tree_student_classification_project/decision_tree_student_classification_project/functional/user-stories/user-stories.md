# User Stories

## US-01 Login
Sebagai admin, saya ingin login agar hanya pengguna berwenang yang dapat menggunakan sistem.

## US-02 Kelola Dataset
Sebagai admin, saya ingin mengunggah dataset quiz online agar data peserta didik dapat digunakan untuk klasifikasi.

## US-03 Data Preparation
Sebagai admin, saya ingin data disiapkan sesuai kebutuhan model agar proses klasifikasi dapat dijalankan dengan konsisten.

## US-04 Training Model
Sebagai admin, saya ingin melatih C4.5 dan Random Forest agar keduanya dapat dibandingkan pada tahap evaluasi.

## US-05 Evaluasi
Sebagai admin, saya ingin melihat confusion matrix dan accuracy agar dapat memahami kinerja model.

## US-06 Knowledge/Rules
Sebagai admin, saya ingin melihat pohon keputusan dan rule C4.5 agar dasar keputusan model dapat digunakan pada deployment.

## US-07 Single Record Test
Sebagai admin, saya ingin memasukkan nilai dan jumlah sesi satu peserta didik agar sistem memberikan klasifikasi.

## US-08 Multi Record Test
Sebagai admin, saya ingin mengunggah CSV agar sistem dapat mengklasifikasikan banyak record sekaligus.
