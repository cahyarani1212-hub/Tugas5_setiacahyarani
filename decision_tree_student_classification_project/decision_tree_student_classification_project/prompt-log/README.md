# Prompt Log

Folder ini disediakan untuk mencatat prompt yang digunakan selama pengembangan dokumen proyek.

## Basis sumber
Dokumen proyek ini disusun berdasarkan jurnal Imam Sutoyo (2018), *Implementasi Algoritma Decision Tree Untuk Klasifikasi Data Peserta Didik*.

## Prinsip
- Terminologi dan struktur CRISP-DM mengikuti jurnal.
- Atribut dataset mengikuti penjelasan jurnal.
- Hasil eksperimen mengikuti angka yang tertulis pada bagian hasil.
- Ketidakkonsistenan internal jurnal dicatat, bukan dikoreksi tanpa bukti.
